# 7K Group

  **Building Inari: the platform control plane that builds its own catalog.**
</div>

7K Group builds **Inari**, a multi-tenant Internal Developer Platform for Kubernetes and AWS. Inari discovers what clusters actually run, turns those capabilities into a living catalog, and delivers golden paths through GitOps.

7K Groupは、マルチテナント型の内部開発者プラットフォーム「Inari」を開発しています。
