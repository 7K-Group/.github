# Brand asset provenance

The SVG assets in this directory are unmodified copies from the public [7K-Group/7k-design-system](https://github.com/7K-Group/7k-design-system) repository:

- `logo-7k.svg` ← `build/logos/logo-7k.svg`
- `logo-7k-light.svg` ← `build/logos/logo-7k-light.svg`
- `icon-7kgroup.svg` ← `build/icons/icon-7kgroup.svg`
- `icon-7kgroup-light.svg` ← `build/icons/icon-7kgroup-light.svg`

`avatar.png` and `social-preview.png` are rendered compositions using the source icon and wordmark. The social preview is 1280×640 pixels; the avatar is 512×512 pixels.
